## 三句话上手

1. **配置** 页新建服务器配置：填 frps 地址、端口、Token，保持「状态监控」开启
2. 添加代理规则（TCP：本地 22 → 远程 6001）
3. 回**主页**点「启动」，日志出现 `login to server success` 即成功

## 常用入口

- 手机浏览器查看运行状态：`http://127.0.0.1:7400/static/`（用户名/密码见配置中的「状态监控」）
- 日志页右上角「分享」可导出全文，反馈问题时附上
- 设置 → frpc 引擎 可查看引擎版本与安装路径

## 版本

- App：设置 → 关于
- 引擎：`androidApp/src/main/assets/frpc/VERSION`（构建时写入）
