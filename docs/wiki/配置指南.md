# 配置指南

App 的配置界面与 `frpc.toml` 一一对应。本文按区块说明，末尾给出各代理类型的完整示例。

## 全局

| 字段 | 对应 frpc.toml | 说明 |
| --- | --- | --- |
| 服务器地址 / 端口 | `serverAddr` / `serverPort` | frps 地址。**kcp/quic 时必须填服务端对应监听端口**（见[协议兼容性](协议兼容性.md)） |
| 用户名前缀 | `user` | 代理名会变为 `{user}.{proxy}`，多人共用 frps 时区分 |
| 客户端 ID | `clientID` | 可选，便于在服务端识别 |
| 首次登录失败即退出 | `loginFailExit` | 默认关闭，断开后持续重连（手机网络切换友好） |

## 认证

| 字段 | 说明 |
| --- | --- |
| 认证方式 | `token`（默认）或 `oidc`（oicd 需在 frpc.toml 手写额外参数，App 仅透传 method） |
| Token | 与服务端 `auth.token` 一致 |

## 状态监控（本机接口）

| 字段 | 对应 | 说明 |
| --- | --- | --- |
| 启用状态监控 | `webServer` 段 | 开启后 App 能读取代理在线状态、**实际分配端口**、CPU/内存；关闭则状态只能靠日志推断 |
| 监听地址 / 端口 | `webServer.addr` / `port` | 默认 `127.0.0.1:7400`，只监听本机，不对外暴露 |
| 用户名 / 密码 | `webServer.user` / `password` | Web 控制台与接口鉴权，默认 `admin/admin`，建议修改 |

> 安全提示：不要把监听地址改成 `0.0.0.0`，否则同网段任何人都能读取你的代理信息。

## 传输

| 字段 | 对应 | 说明 |
| --- | --- | --- |
| 连接协议 | `transport.protocol` | `tcp`（默认）/`kcp`/`quic`/`websocket`/`wss` |
| TCP 多路复用 | `transport.tcpMux` | 默认开，需与服务端一致 |
| 预连接数 | `transport.poolCount` | 预建连接降低首包延迟，0 表示不预建 |
| 启用 TLS | `transport.tls.enable` | frp ≥ 0.50 默认开；服务端不支持时关闭 |
| 代理服务器 URL | `transport.proxyURL` | 走 http/socks5 代理连 frps，仅 `tcp` 协议有效 |

## 日志与 UDP

| 字段 | 说明 |
| --- | --- |
| 日志级别 | `trace`/`debug`/`info`/`warn`/`error`，排查问题用 `debug` |
| UDP 包大小 | `udpPacketSize`，影响 udp/sudp 代理，默认 1500，需与服务端一致 |

## 代理规则

带 `*` 为必填。保存时会校验，不通过会阻止保存并列出原因。

### TCP

```
名称 *      ssh
类型 *      TCP
本地 IP *   127.0.0.1
本地端口 *  22
远程端口 *  6001        # 0 = frps 随机分配
```

### UDP

同 TCP，类型选 UDP。适合 DNS、游戏等。

### HTTP / HTTPS（需要 frps 配 vhost 端口）

```
名称 *      web
类型 *      HTTP
本地 IP *   127.0.0.1
本地端口 *  80
子域名       web01
自定义域名   web01.example.com
```

- 需 frps 配置 `vhostHTTPPort`（及 `subdomainHost` 才能用子域名）
- **HTTPS 代理是 TLS 透传**：本地服务必须自己支持 HTTPS，frps 只按 SNI 路由

### STCP / SUDP / XTCP（私密通道）

```
名称 *      secret_ssh
类型 *      STCP
本地 IP *   127.0.0.1
本地端口 *  22
密钥 *      your-secret
允许用户    *            # * = 同账号全部
```

访问端需要配置**访问者**（同配置页「访问者」区块）：

```
名称 *      secret_ssh_visitor
类型 *      STCP
目标代理名 * secret_ssh
密钥 *      your-secret
绑定地址    127.0.0.1
绑定端口    9000
```

之后访问本机 `127.0.0.1:9000` 即走隧道。SUDP 为 UDP 版本，XTCP 会尝试 P2P 直连。

### TCPMUX（需要 frps 配 tcpmux 端口）

```
名称 *      mux
类型 *      TCPMUX
复用器 *    httpconnect
本地 IP *   127.0.0.1
本地端口 *  10701
自定义域名  tunnel1
```

需 frps 配置 `tcpmuxHTTPConnectPort`。

## 导入 / 导出

- **导出**：配置列表 → 卡片右上角菜单 → 导出，得到标准 `frpc.toml`，可给其它 frpc 使用。三种落地方式：
  - **保存到文件（.toml）**：调起系统文件选择器，可存到「下载」「文档」或任意目录
  - **分享**：交给其它 App（微信、邮件、网盘等）
  - **复制到剪贴板**：临时粘贴到聊天窗口
- **导入**：配置列表底部「导入」（没有配置时，空状态卡片里也有入口），选择 `.toml` 文件

> 文件选择器按 `*/*` 过滤：`.toml` 在 Android 上没有登记标准 MIME，若按 `text/*` 过滤会在选择器里被隐藏，看起来像"无法选中文件"。

导入时会：

- 忽略未建模字段（plugin / healthCheck / annotations / metadatas 等）
- **自动清理该代理类型不支持的字段**（例如 sudp 带 `remotePort` 会让 frpc 启动失败，导入时会去掉）

## 多配置

支持保存多个服务器档案，主页顶部可切换；「设为默认」的配置用于开机自启。
