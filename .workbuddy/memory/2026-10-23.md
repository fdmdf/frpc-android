# 2026-10-23 frpc-android 项目启动

## 任务
实现 frpc 安卓客户端，参考 luckjiawei/frpc-desktop 的界面功能；要求：安装包小、运行快、跨平台。

## 关键决策
- 技术栈：Kotlin Multiplatform（shared: android+jvm 双端逻辑层）+ Jetpack Compose M3（原生、包体小、启动快）
- frpc 引擎：frp v0.71.1 源码 Go 交叉编译（arm64 静态 + x86_64 NDK cgo），assets 分发、按 ABI 安装到 filesDir/bin
- 版本矩阵（重要）：AGP 8.13.2 + Gradle 8.13 + Kotlin 2.4.21 + compose-bom 2026.06.00（compose 1.11.3）。
  踩坑记录：① AGP 9.x 内置 Kotlin 2.2.10 且禁显式 kotlin.android 插件、KMP 组合方式大改 → 弃用；
  ② compose-bom 2026.09（compose 1.12）要求 compileSdk 37，AGP 8.13.2 最高 36 → 降 BOM；
  ③ KMP 的 androidLibrary{} 新 DSL 仅 AGP9 支持，AGP8 用 androidTarget() + 独立 android{} 块；
  ④ kotlin{compilerOptions{}} 顶层是 KotlinCommonCompilerOptions 无 jvmTarget → android 目标靠 AGP compileOptions 同步，JVM 目标用默认。
- ktoml 0.7.1 缺陷：[[proxies]] 内点分键（transport.x=y）每个键生成一个同名子表导致解码丢失
  → FrpcToml.decode 解析后 mergeDuplicateTables 合并同名子表修复（有真实 frpc 示例解析测试覆盖）
- 导航不用 Navigation-Compose（减依赖），自写 AppNavigator 返回栈；编辑草稿放 Activity 级 ConfigEditorStore 防旋转丢失
- 持久化：JSON 文件（configs.json 原子写）+ SharedPreferences，不引 Room/KSP
